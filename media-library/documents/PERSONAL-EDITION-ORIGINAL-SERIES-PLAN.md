# 個人DB改修：原作とシリーズの分離・既存データ移行

決定日：2026-10-23。

**状態：仕様の記録のみ。これまでの実装保留を維持し、コード変更・実DB更新・配備は行わない。**

## 分離する意味

- 原作・題材：二次創作の元になった作品。例：ブルーアーカイブ。
- シリーズ：登録する漫画・同人誌自体の連作。
- 両項目を独立して持ち、一つの作品に両方を設定できる（既存合意）。

## 現行DBのシリーズ項目の移行先

ユーザーが現行DBを確認し、次の移行方針を指定した。

| 現在の主表記 | 移行先 |
| --- | --- |
| 英語表記のシリーズ | すべて原作欄 |
| 日本語が主表記で、ブルーアーカイブに該当 | 原作欄 |
| 日本語が主表記で、グラブルに該当 | 原作欄 |
| その他の日本語が主表記の項目 | シリーズとして維持 |

主表記を基準にする。別名に英語・日本語が含まれるだけで移行先を反転させない。名称・別名や作品との関連付けを保持して分類を変更し、作品自体を統合・削除する処理とは分ける。

これはユーザーが点検した既存データに対する一回の移行規則。今後登録するメタデータについて「英語なら原作、日本語ならシリーズ」という一般規則にしない。

## 実装再開後の確認

- 実際の主名称とIDを読み取り、移行一覧を作る。ブルーアーカイブ・グラブルは実データの名称・別名から対象IDを特定し、無関係な部分一致項目まで移さない。
- 英語／日本語の単純判定ができない混在表記や記号・数値のみ等があれば、ユーザーの点検結果から推測して破壊的に変更せず、対象を一覧で確認する。未確認の件数を確定値として報告しない。
- 移行前バックアップと、移行先別の件数・作品への関連付けの保持を確認する。
- 保存検索・編集画面・インポーター等へ原作とシリーズの区別を反映する具体設計は別途行う。新規取り込み先を表記言語から判定しない。

現在の実データ一覧は今回こちらでは取得していない。現行DBがこの二言語だけで完全に分類できると検証済みという意味ではない。
