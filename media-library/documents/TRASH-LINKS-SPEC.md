# ゴミ箱リンク再利用・リンク検索

2026-10-14。個別操作の実装仕様。カードのソース表示は相談のみ。

## 主リンクの再登録

登録済み作品がゴミ箱にだけ存在するURLでは、作品名とリンクを表示し、完全削除して再利用する確認を出す。
「はい」の後も保存が成功するまで削除しない。保存・削除は同一トランザクションで行い、キャンセル・無効入力・競合・保存失敗では元作品を維持する。
確認時のゴミ箱作品全体のスナップショットを検証し、確認後の復元／編集／リンク変更があれば再確認を要求する。
元作品の他リンクを含む完全削除、評価・マーク・レビューを引き継がないことを確認画面で明示する。
ブックマークレット・共有の完全一致Trash導線から新規ドラフトへ進める。復元を選ぶ場合はゴミ箱画面の既存機能を使う。

## 副リンクとして統合

編集フォームに副リンクを入力して保存／取得する場合、または新規ドラフトから既存作品への副リンク追加を選ぶ場合に確認する。
対象リンクと、選択したタイトル・表紙・カテゴリ・言語・ページ数・作者・サークル・タグ・シリーズ・キャラクターを反映する。
スカラーの既存値は上書きチェック、複数値はマージ／上書き／そのまま。空の対象欄は補完、空の取得値は維持、同一値は変更しない。
他の元リンクは自動転送しない。完全削除によって失われることを確認画面で知らせる。
統合先の評価・マーク・レビュー、既存主リンクは保持。ゴミ箱側の完全削除は対象の保存成功時にのみ実行する。
既存の有効作品で同じURLを使用中なら再利用不可。所有者外のゴミ箱作品は対象外。
一括ブックマーク／Favorites取込は従来通り重複URLをスキップし、確認なしの完全削除は行わない。

## 検索

- `source:nhentai`：全ソースリンクのURLまたは保存ラベルの部分一致。
- `url:momon-ga.com`：全ソースリンクのURLのみ部分一致。
- `label:Hitomi`：保存ラベルのみ部分一致。空ラベルからサイト名を推測しない。
- `url:"https://example.com/work/"`：スラッシュを含むURLは引用符で囲む。
- `source:hitomi/source:nhentai`：いずれか。`-source:nhentai`：除外。
- 主・副どちらも対象。大文字小文字を区別せず、ゴミ箱作品は通常検索から除外。
- 通常のフリーワード検索にはURL・ラベルを追加しない。検索ヘルプに新しい項目を記載。

## カード表示（2026-10-14 実装）

カード左下に主ソースを小さなチップで表示。保存ラベルを優先し、空ラベルなら既知のサイト名（Hitomi／nhentai／momon-ga）またはwwwを省いたホスト名にフォールバック。主リンクがなければ先頭リンクを使う。リンクがない作品は表示しない。
主リンク以外のURL数を `nhentai +2` のように表示。同じサイトの別リンクも数える。長い表示名は省略し、PCのホバーでは全表示名を確認できる。
タップで全ソース一覧のダイアログを開き、ラベル・実ドメイン・URL・主リンクの印を表示する。一覧のリンクは新しいタブで元サイトを開く。×またはEscapeで閉じ、検索条件・スクロール・選択状態を維持する。
評価・右下のマークと視覚的に競合しにくい。任意ラベルと実ドメインを併記する展開部分を用意する。
既存の右下のマークとフッターを共有し、互いに重ならないように配置する。カードから作品を開くリンクとソースボタンは独立した操作。アイコンやfaviconの外部取得、追加のAPI照会は行わず、取得済みリンク情報だけで表示する。
