# DLsite・FANZA／DMMブックス インポーター仕様

2026-10-14。ユーザーが実装承認。取得方法の根拠は[DLSITE-DMM-RESEARCH.md](DLSITE-DMM-RESEARCH.md)。個人用Folioへの追加。正規購入リンクの全件探索（F-019）は含まない。

## 対象と入口

- DLsite：home／maniax／girls／booksのRJ・BJ漫画商品ページ。PC版と-touch版、dlsharing.comの同形共有リンクを受け付ける。VJ、音声・ゲーム・CG、購入履歴は対象外。
- FANZA同人：www.dmm.co.jp/dc/doujin/-/detail/=/cid=d_商品ID/ のコミック。
- DMM／FANZAブックス：book.dmm.com／book.dmm.co.jp/product/シリーズID/商品ID/ の漫画。latest、試し読み／読書位置、旧詳細URL・別の短縮リンクは初期対象外。
- 個別インポート・ブックマークHTML一括・共有・ブックマークレットを共通アダプターへ接続。nhentai Favoritesの対象は従来通りnhentaiだけ。

## 取得項目

元の商品名を表示タイトルにする。DLsiteの割引率・販売元・サイト名付きog:titleではなくh1#work_nameを取得。FANZAは商品h1と商品情報欄、ブックスは現在の商品に対応するProduct/Book JSON-LDと作品詳細欄を使用。おすすめ・レビューの情報を混ぜない。

作者／著者／作家→author、同人サークル→circle、明示されたシリーズ→series、ジャンル→tag、明示ページ数→pages。同人商品→doujinshi、商業漫画→manga。DLsite商業書籍のtable#work_makerの著者も取得する。
出版社・レーベル・掲載誌・価格・販売サイトの評価・レビューは取り込まない。作者欄がなければサークルを作者へコピーせず、独立したページ数がなければ推定しない。言語とキャラクターは初期版では空欄。
表紙は商品ページのog:imageの主画像。サンプル画像や本文1ページ目を使わない。取得不能な表紙は警告し、他のメタデータは取得できる。
タグは既存の無属性／最多属性方式を共有。別名照合・曖昧候補の確認は既存の処理を使う。別サイトの近い語を推測で同義語統合しない。

## 保存・URL比較・候補確認

利用者が渡した元URLを保存する。共有／スマホURLからネットワーク上の任意転送をたどるのではなく、商品IDを読み取って正式なPC商品URLを生成して取得する。
比較キーだけを商品IDで正規化し、追跡クエリ・フラグメント・共有ドメイン・スマホ表記を区別しない。DLsiteはRJ/BJ商品ID、FANZA同人はd_商品ID、DMM/FANZAブックスはcontentId。ブックスのseriesIdだけでまとめない。別商品IDの単話・巻・版は別作品。
Migration 10は既存の該当リンクのurl_keyとsource_claimsを再構築する。元URL、作品ID、作品情報は変えず、衝突しても既存作品を自動統合・削除しない。
新規取得リンクのラベルはDLsite／FANZA同人／FANZAブックス／DMMブックス。手動の既存ラベルは維持する。カードでも空ラベルからサイト名を補完する。
登録済みURLは開くかバッチでスキップ。ゴミ箱URL再利用は既存の確認方式。別サイトの同名作品は既存の副リンク候補確認を使う。比較用タイトル候補では【版名】等の直前の空白差を吸収するが、保存タイトル・版名は維持し、自動統合しない。ページ数・作者等の差も従来の候補説明に残す。
既存作品への明示再インポートは従来通り項目別の上書き／マージ／維持と空欄補完。購入リンクを付けるだけの場合はsource-attachにより他の情報・主リンクを維持する。

## 通信と年齢確認

APIキー・DMMログイン・ブラウザCookieの取り出しは不要。成人利用者である現オーナーが正規の年齢確認を了承している。FANZAが年齢確認へ転送した場合、公式のyesButtonLinkを解析し、元の対象商品に戻るdeclared=yes経路だけをたどる。
age_check_doneだけをプロセスRAMで保持し、ゲストID・ログインCookieを保存しない。DB・バックアップ・ログ・GitにCookieを含めず、再起動で消える。ログイン／CAPTCHA／他ホストへの転送は中止する。将来の複数ユーザー公開版での年齢確認設計とは分ける。
メタデータは固定ホスト・固定商品パス、年齢確認は固定ホスト・固定パス・同一return URLに制限。実接続のDNSを公開IPに固定し、TLS証明書を検証する。各リクエスト25秒、HTML4MiB、解析深度・ノード・メタデータ数に上限。各プロバイダーの取得開始は3秒以上空ける。取得待ち・読取中にバッチの一時停止／キャンセルを確認する。HTTP429・503等は既存のジョブ再試行処理へ渡す。

## 表紙

img.dlsite.jpの主画像、doujin-assets.dmm.co.jpの当該商品pr画像、ebook-assets.dmm.com／ebook-assets.dmm.co.jpの当該商品pl/ps画像だけを許可する。商品IDに一致する画像URLだけを取り込み、任意画像プロキシにはしない。
既存のRAMキャッシュ・作品表紙中継・入力プレビューに接続。画像本体をDBやディスクへ保存しない。2MiB上限・公開IP固定・TLS・期限・MIME/シグネチャ検証、no-store応答は既存方針を維持。JPEG・PNG・WebPに対応。画像取得に年齢確認Cookieを送らない。

## 検証・残る制約

合成HTMLで取得範囲・作者欠落・出版社除外・カテゴリ拒否、URL境界、年齢確認と外部転送拒否、画像境界、キャンセル、既存手動リンクの移行保全、タグ頻度方式、ブックマーク名優先、登録確認・再取得・副リンク追加を検証する。
ユーザー指定8商品のライブ取得と、別DBの安全な合成商品で画面導線を確認。実商品の表紙はメモリ内で応答を検証し、画像を表示・保存しない。すべての商品・大量取得・別サーバー／海外からの可用性は保証しない。実行記録は[VERIFICATION.md](VERIFICATION.md)へ追加。
