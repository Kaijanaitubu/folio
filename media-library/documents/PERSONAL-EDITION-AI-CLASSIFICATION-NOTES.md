# 個人DB：AI区分の取得元対応・相談

2026-10-23。調査・仕様相談のみ。実装・DB変更は保留。

## ユーザーの指摘

前の開発側案「使用なし／補助利用／生成主体／不明」は未承認。取得元に情報がなければ細分化できないため、販売サイトの区分に合わせるべきとの意見。Folio独自に画像や制作工程を推定して分類する合意はない。

## 公式情報の確認

| サイト | 確認できた区分・留意点 |
| --- | --- |
| DLsite | 「AI生成作品」「AI一部利用」。2022-11-30付公式告知で、主なコンテンツに生成物を用いる場合と、背景等の限定利用を分ける。自動補正・補間等をこの一部利用に含めるとはしていない |
| FANZA同人 | 公式ヘルプで「AI」（AI生成）と「一部AI」（一部AI利用）。登録時のサークル・制作者の設定を反映すると説明 |
| pixiv | AI生成作品の設定がある。全て・ほとんどをAI生成した作品を対象にし、補助的コンテンツの利用は生成設定を要しない場合がある。非該当を「AI完全不使用」と同義にしない |

根拠（2026-10-23確認）：[DLsite公式告知](https://info.eisys.co.jp/dlsite/bb3b0b976520e0fd)、[FANZA同人公式ヘルプ](https://support.fanza.jp/doujin/article/48426)、[pixiv公式ヘルプ](https://www.pixiv.help/hc/ja/articles/13276278766489-AI%E7%94%9F%E6%88%90%E4%BD%9C%E5%93%81%E3%81%A8%E3%81%AF%E3%81%AA%E3%82%93%E3%81%A7%E3%81%99%E3%81%8B)。DLsite告知の古い公開日は明示し、全サイトの定義が完全一致するとはしない。実際の各インポーターで区分を取得できることを今回検証したものではない。

## 承認済みの基本区分

2026-10-23、ユーザーが以下の4区分と取得元基準の方式を了承。実装再開は本番の改修ではなく、別の架空データによる画面プロトタイプを作る指示。複数ソース競合等は引き続き未決。

- 共通の検索・表示用には「AI生成」「AI一部利用」「非AI生成（取得元基準）」「不明／記載なし」を候補とする。
- 元サイトの明示区分を対応付けるだけとし、独自に補助の程度・使用比率を判定しない。
- 区分がない／取得できない場合は不明。ラベルがないことから「AI不使用」を推定しない。
- 「非AI生成」は元サイトから明確に取得できる場合の区分であり、制作中にAI機能を一切使っていないことを保証する表示にしない。
- 取得元URL・元の区分名を保持し、対応先の区分の根拠を確認可能にする案。取得元同士の区分差を消してしまわない。
- 複数ソースで食い違う場合の代表値・手動上書きの扱いは未決。未承認の優先順位でAI生成／非AI生成を断定しない。
- 4区分は上記の了承で確定。細かな表示文言はプロトタイプを見て調整する。
