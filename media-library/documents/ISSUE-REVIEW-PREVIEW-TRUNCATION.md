# レビューのプレビュー短縮表示

記録日：2026-10-16  
管理ID：F-035  
状態：実装済み（2026-10-16）  
関連：[ロードマップ](ROADMAP.md)

## 報告内容

作品共有画面で「レビューを含める」にチェックすると、レビュー全文がプレビューされる。レビューのプレビューは冒頭だけに短縮し、続きがあることを省略記号で示したい。

## 希望する動作

- レビューのプレビューは先頭約30〜40文字を表示する。
- 元レビューが表示上限を超える場合、末尾に「…」を付ける。
- 作品共有画面以外にもレビューのプレビューを表示する箇所があれば、同じ短縮ルールを使う。
- 全文表示が必要なレビュー本体は、プレビューとは別に従来どおり読めるようにする。

## 完了条件

- [ ] 共有画面のレビュー選択プレビューが短縮表示される。
- [ ] ほかのレビュー・プレビュー箇所を確認し、同じルールが適用される。
- [ ] 上限より短いレビューは全文を表示し、省略記号を付けない。
- [ ] 上限を超えるレビューは指定長で省略し、「…」を表示する。
- [ ] 共有内容や保存データのレビュー本文は切り詰められない。

## 実装時の確認事項

- 表示上限を30〜40文字の範囲で統一する。
- 日本語、英語、改行、絵文字を含む文字列で表示が崩れないようにする。
- 全文表示とプレビュー表示を取り違えないよう、対象箇所を洗い出す。

今回はロードマップと課題文書への記録のみ。コードや作品データは変更しない。

## 2026-10-16 実装

ユーザーがF-035の着手を承認。共有設定ダイアログ内のレビュー表示を、先頭40文字（対応ブラウザーでは書記素単位）＋超過時だけ「…」にした。改行・連続空白は表示上1空白へまとめる。短いもの・ちょうど40文字は省略記号を付けない。Intl.Segmenterで絵文字の連結・結合文字を分断しない。非対応の旧ブラウザーではUnicodeコードポイント単位にフォールバックする。

短縮は表示直前に適用し、その後HTMLエスケープする。DB・共有作成API・共有スナップショット本文・詳細ページのレビュー全文には適用しない。ほかのフロントエンドを確認し、レビュー本文の表示をプレビューとして短縮する変更はしない。

`test_review_preview.mjs`で英語・日本語・40文字境界・改行・複合絵文字・結合文字を確認。詳細表示の回帰スクリプト、および隔離環境の共有テスト8件も成功。F-036のカード掲載情報は別途構想確認待ち。
