# 作品詳細・入力画面の操作プロトタイプ

2026-10-23。ユーザーの依頼により、会議仕様を触って調整するための独立した試作を作成。本番DB・API・インポーターに接続しない。現行アプリのファイル・DB移行やVPS配備は行っていない。

## 開く

試作配信用のHTTPサーバーをこのPCの127.0.0.1:8766で起動済み。

- [作品詳細](http://localhost:8766/prototypes/work/#/work/atelier)
- [作品入力](http://localhost:8766/prototypes/work/#/edit/atelier)

このPCだけで開ける。スマホ実機・別PCからアクセスできるように公開しているわけではない。端末間同期なし。ブラウザやポートが変わると保存領域も別になる。

サーバーを止めた後は、PowerShellで **media-library/** を作業ディレクトリとして次を実行する。

```powershell
.\preview-work.ps1
```

ポートが既存アプリ等で使われている場合は停止させず、`-Port`で空きポートを指定する。通常のFolioサーバーを起動する必要はなく、Python標準の静的配信だけを使用する。Ctrl+Cで終了。

## 試せること

- 架空の3作品の切替、新規作成、詳細→編集→保存→詳細の往復。
- 黒・オレンジの配色、日本語／英語UI、PCとスマホ幅の配置。
- 漫画／CG・イラスト／その他、同人／商業、一次創作／二次創作／未設定。
- 二次創作時に原作・キャラクターを基本情報へ表示。それ以外は詳細情報へ移し、登録値は消さない。
- 作者・サークル・原作・シリーズ・キャラクターの選択・新規追加・解除。タグの属性変更。
- rating0と独自評価3軸、レビュー、5マーク。詳細のマークはその場で保存、作品編集の値は保存ボタンで確定。
- 主リンクの切替、ラベル・別版名、本編／サンプル／その他・未確認。
- リンクごとの複数言語・ページ数・複数日付。年／年月／年月日、その他の日付の任意名。
- 全リンクの言語の重複なし表示。本編の最優先ソース群内で最大ページ数。発売日優先→公開日、その種別内で最優先群の最古日付。
- 代表ページ数・日付のⓘで採用元を確認。左下（スマホでは末尾）の「採用優先度を試す」で仮の優先度を変更。
- 年齢区分、取得元に合わせたAI4区分・根拠メモ。
- 収録先のサンプルエントリへの接続と、名前・URLの同時保存。未登録収録先も記録可能。
- 原作が一つなら保存時にキャラクターを自動接続、複数なら全組合せを作らず既知の対応を維持。
- キャラクター名から接続編集を開き、明示解除と手動再接続。解除後の自動復活を防ぐ。
- 未保存で画面を離れる際の確認、入力エラー時の詳細欄展開、開閉状態の端末内記憶。

## 保存とリセット

保存先はブラウザのLocalStorageの専用キー`folio.work-prototype.v1`。Folioの実データを読み取る機能も書き込む機能もない。サンプルの「リセット」で初期状態へ戻せる。

キャラクター辞典の接続編集はその辞典への操作として即時保存する。作品の編集キャンセルで辞典の変更は巻き戻さない。作品の原作・キャラクター自体は接続解除で削除しない。

表紙は自作SVG、作品名・作者・メタデータは架空。サンプルの外部リンクはすべてexample.com。任意の外部画像URLを入力した場合はブラウザがその画像を直接読むが、画像ファイル自体を試作の保存領域へ取り込まない。

## 試作上の制限・仮置き

- 実インポート・既存データ移行・会員認証・公開カタログ・公開共有は未実装。共有アイコンはこの制限を説明する。削除は試作一覧だけに適用。
- ソース優先度の数値は検証用で、正式な優先表の確定ではない。
- 不完全日付は精度を保って保存。年／年月の比較順は仮に同じ接頭部分の詳細日付より先へ置く。厳密な重なり・予定日の扱いは本実装前に詰める。
- 年齢区分の選択肢や細かな画面配置は、触って確認するための案を含む。AI4区分以外の直前の提案まで一括で確定済みとはみなさない。
- 自動インポートによる創作区分の判定は試せない。手動で区分を切り替えた場合の配置・データ保持を試せる。
- 評価軸名・段階数の管理画面は対象外。総合評価の移行式は純粋関数とテストを用意したが、実DBへ適用していない。サンプルのrating0は独立して編集する。
- 複数タブでは未編集の画面をLocalStorage変更で更新するが、同時編集の競合解決は本番仕様の代替ではない。まず同じタブで表示と編集を行き来して確認する。
- キャラクター自動接続は試作辞典内だけの挙動。既存キャラクターの自動分割や共用側への反映は行わない。
