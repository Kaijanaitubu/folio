# 個人DB改修：カテゴリ分離とrating0の追加

決定日：2026-10-20。

**状態：仕様の記録のみ。ユーザーが「まだ処理はしなくていい」と指定。実装、DB移行、既存評価の計算・書き込み、配備は開始しない。**

## 1．カテゴリの分離

作品形式を次の3分類にする。以前の「漫画／CG・イラスト集」の案に「その他」を追加する。

| 作品形式 | 対応する現行カテゴリ |
| --- | --- |
| 漫画 | manga、doujinshi |
| CG・イラスト | artist cg、image set |
| その他 | game cg |

- 作品形式とは別に同人／商業の刊行区分を持つ既存合意を維持する。
- 現行mangaは漫画＋商業、doujinshiは漫画＋同人へ移行する。
- Image setは独立カテゴリとして残さず、CG・イラストへまとめる。
- ユーザーによれば現在のDBにgame CGはないが、分類上はその他へ対応させる。実際の保存件数は未確認。
- artist cg／image set／game cgという旧カテゴリ名だけから同人／商業を決めつけない。これらの刊行区分の補完方法は未確定。
- 未設定の既存作品をどれかへ強制分類する合意はない。入力必須化やその他への一括変換を今回決定したものではない。

新しい内部値、旧検索条件の互換、既存インポーター・一括編集・共有・バックアップへの反映は実装時に設計する。個人DBの自由な登録を、共用カタログの対象範囲で制限しない。

## 2．固定の総合評価rating0

既存合意どおり、星1〜5の総合評価を固定軸rating0として追加する。未評価を許容し、既存の独自評価rating1以降の番号・値は維持する。

今回、既存3軸からrating0の初期値を作る仕様を承認。前回の「既存評価をコピーせず全件未評価」という開発側提案より、今回の計算ルールを優先する。

### 初期値の計算順

1. rating1（ストーリー）またはrating2（淫靡さ）が星5なら、**他の軸が未評価でもrating0を5**にする。
2. 上記に当たらず、既存3軸すべてが評価済みなら、**3軸の合計÷3を小数点切り上げ**してrating0へ設定する。
3. 上記に当たらず、いずれかに未評価があれば、rating0も未評価のままにする。未評価を0として計算せず、評価済み軸だけで平均もしない。

ユーザーの「10以上12未満」は、今回の確認で**合計10〜12（12を含む）が星4**と確定。

### 3軸がすべて5段階の場合の対応表

| 3軸の合計 | rating0（星5の特例がない場合） |
| --- | --- |
| 3 | 1 |
| 4〜6 | 2 |
| 7〜9 | 3 |
| 10〜12 | 4 |
| 13〜15 | 5 |

例：rating1=5、rating2=1、3軸目=1なら、平均の切り上げは3だが特例でrating0=5。rating1=2、rating2=2、3軸目=5なら、特例は適用せずrating0=3。

### 移行前に実装側で確認する事項

- 実際の既存3軸のID・番号・名称・最大値を読み取り確認する。今回VPSへの照会はsudo認証で実行できず、現行設定の確認は未完了。
- この計算は3軸が5段階という前提。別の段階数・想定外の軸があれば、未合意の正規化や軸選択で処理しない。
- 追加の独自評価軸まで平均に含めない。実際に用いる3軸目は既存設定を確認して特定する。
- rating0の手動変更後に再計算し続ける機能を今回依頼されたわけではない。既存3軸からの初期値移行と、以後の独立した総合評価を区別する。
- 移行の再実行で手動評価を上書きしないこと、事前バックアップ、未評価・特例・境界値の件数確認、ゴミ箱内作品の移行対象は実行前に具体化する。
