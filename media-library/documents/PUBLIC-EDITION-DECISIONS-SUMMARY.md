# Folio 正式版 — 企画と決定事項のまとめ

更新：2026年10月18日 ｜ 読了目安：約5分

正式版の会議で合意した方針の要約です。現行版にすべて実装されているという意味ではありません。末尾の未決事項を除き、細かな実装方法・数値は今後詰めます。

## 1．何を作るか

**いろいろなサイトで見つけた成人向け漫画・CG集を、自分の本棚として保存・整理し、その記録から作品情報の共用カタログを育てるサービス。**

主役は個人用データベースです。公開対象にならない作品や、情報を取得できないリンクでも、個人の保存を止めません。共用カタログは作品情報と正規の販売・公開先を案内するもので、作品ファイル本体を集めて配布するサービスではありません。

| 機能 | 目的・公開範囲 |
| --- | --- |
| 個人DB | 自分の保存・整理・検索。ライブラリ全体やプロフィールの公開は初期対象外 |
| 共用カタログ | 利用者の作品メタデータを集約し、検索・発見・正規購入を支援 |
| 個人共有ページ | 本人が選んだ個人記録を第三者へ共有。共用カタログとは別機能 |

個人共有は発行時点の固定スナップショットを基本とし、いつでも解除できます。マークも本人が選んで共有可能です。自動更新は将来候補です。

## 2．対象作品と掲載条件

| 対象にする | 対象にしない |
| --- | --- |
| 漫画・同人誌・CG集・イラスト集・差分集 | 写真・完全な単独イラスト |
| 1ページ漫画、漫画に付随動画がある投稿の静止画部分 | 動画・ゲームそのもの、非公式のゲーム抽出画像 |
| AI生成・AI補助作品、独立したイラスト調3DCG集 | 上記の対象外条件に該当するもの |

商業・無料・支援者限定・SNS投稿・未販売という公開形態では除外しません。成人向けが中心ですが、関連する全年齢作品の登録を一律には排除しません。

- **利用者は18歳以上。** 初回の年齢確認前は作品画像を表示しません。確認後は通常表示を基本に、ぼかしへ切り替えられます。
- 年齢区分は任意の詳細情報。初期値は成人向けで、取得元に明示があれば反映します。
- AIの使用区分も検索・除外でき、使用有無が分からない場合は未確認を許容します。
- 転載サイトのリンクも個人保存は可能ですが、共用カタログには掲載しません。
- **共用の内部情報に正規・作者公式作品への確定した接続がなければ、公開集計は保留、評価・レビューの投稿も不可。** 個人エントリへの正規リンク追加自体は必須ではありません。

## 3．作品情報の持ち方

個人DBと共用カタログは基本構造をできるだけ揃え、個人固有・公開固有の情報は分けます。2026-10-24更新：個人の詳細表示は下部の詳細情報も常時表示し、編集画面は各セクションを初期展開・個別開閉できる構成にします。[個人DB改修の統合仕様](PERSONAL-EDITION-WORK-IMPLEMENTATION-SPEC-20261024.md)。本番適用は保留中です。

| 項目 | 決定した扱い |
| --- | --- |
| 形式・区分 | 「漫画／CG・イラスト／その他」と「同人／商業」を分離。旧「漫画」は漫画＋商業、旧「同人誌」は漫画＋同人へ移行 |
| 作者・サークル | 両方を残す。サイト別ID・外部リンクを対応付け、詳細ページで情報を確認できる |
| 作者本人の接続 | 所有確認と公開上の本人接続を分離。公開接続は本人が選ぶ |
| 原作・シリーズ | 二次創作の元作品と、その漫画自体の連作を別項目にする |
| キャラクター | 任意で登録。原作との対応・別名を持ち、同名の別キャラクターを区別する |
| 収録関係 | 単話と単行本・雑誌等を別作品として接続。個人側でも任意に登録可能 |
| 言語 | ソースリンクごとに設定。言語の違いだけで作品詳細を分けない |
| 発売・公開日／ページ数 | リンクごとに保存。個人DBの概要は主リンクの値。共用カタログの採用優先度による代表値選択とは分ける（2026-10-24訂正） |
| タイトル | 正規ソースを基本とする。SNSは投稿文を仮採用し、投稿文なしなら「タイトルなし｜作者｜投稿日」等を生成 |

日付やページ数の検索では、言語・販売先を指定した場合、その条件に合うリンクの範囲で判定します。サンプル・収録誌全体のページ数を本編の値と混同しません。

同じ内容の販売先違いは複数リンクとしてまとめ、巻・単話・収録先は区別します。サンプルは本編との対応が分かるまで別作品として掲載可能。Xの連続投稿は先頭への対応を補助しますが、曖昧なものを無理に統合しません。

## 4．タグ・検索を強みにする

**人手で共用タグ辞書を育て、ニッチな行為・シチュエーション・心身の特徴まで細かく探せることを重視します。**

- 個人DBでは共用辞書からタグを選択。辞書外タグも保存できますが、公開の作品集計には加えず、内部で候補を集めて採用を検討します。
- 属性は男性・女性・属性なしを維持。行為者／対象者の解釈はタグごとの定義で整理し、人物・場面単位の注釈は必須にしません。
- タグ等には日英名称・別名・短い説明を用意。説明や翻訳がなくても登録できます。
- 登録数と「適切／不適切」の投票は別集計。投票は内容の存在判定で、中心度や好みではありません。票の割れも表示します。
- 一般公開後は未ログインでもブラウザー単位で投票可能。最低票数・不適切票率等で公開非表示にでき、個人タグは消しません。
- 検索では信頼度を「指定なし／低以上／中以上／高のみ」から選べ、未判定も区別します。

個人検索と公開検索は切り替え式。公開側は関連度・追加順・発売公開日・登録者数・総合評価で並べ替え、シリーズや作者の関係、共通タグから作品を探せる構成です。

## 5．評価・レビューの共有

| 記録 | 個人利用と共用カタログへの投稿 |
| --- | --- |
| 総合評価 `rating0` | 星1〜5固定、未評価可。自動公開設定は初期オフ。有効化すれば変更も追随 |
| 独自評価 `rating1` 以降 | 自由な評価軸を維持。作品ごとに公開する軸を選ぶ |
| レビュー | 作品ごとに明示的に投稿 |
| マーク | 完全に個人専用。共用カタログへの公開・集計はしない |

手動投稿は投稿時点の内容を保ち、明示的な更新で変更します。投稿時に匿名／表示名を選択でき、自動公開の総合評価は匿名が基本。同じ本人の公開評価が衝突したら採用する方を選び、個人保存は止めません。

個人作品の削除・退会時は、公開済みの評価・レビューを残すか撤回するか選べます。退会後に残す投稿は原則「退会済みユーザー」表示で、総合評価の集計にも残します。下書き・非公開記録は公開しません。

## 6．取り込み・更新・使い勝手

- 既存インポーター、共有メニュー、ブックマークレット、まとめて取り込む導線を活かします。PixivブックマークやX等の追加取得も検討対象です。
- 登録済みリンクなら自分の作品を開き、未登録なら取得情報入りの編集画面へ。共用作品も情報をコピーして自分用に保存できます。
- 個人の編集内容は自動上書きしません。再取り込みは比較し、上書き・マージ・維持を選びます。
- 共用のタイトル・表紙は正規ソースと採用優先度で決定。同格なら既存を維持し、より高優先の正常な情報があれば更新します。
- **共用表紙に個人DBの表示画像は利用しません。** 正規ソースから取得し、失効時は別の正規画像か表紙なしにします。
- 共用側は採用元の変更にも追随し、人手の訂正は保護。取得失敗・リンク切れで保存済み情報を消しません。
- 訂正・通報・作者等による掲載取り下げの窓口を用意。公開停止で個人記録まで削除しません。
- 共有URLの外部リンクカードは、作品表紙ではなくFolio共通ロゴを使います。
- 個人データは出力可能。取り込みは追加・マージと自分の全体置換を選べ、運営の全体復旧とは分離します。

## 7．立ち上げ方と収益の方向性

| 項目 | 現在の方針 |
| --- | --- |
| β | 5〜10人の招待制。共用カタログも招待者限定 |
| 移行 | 現行個人版を維持し、別β環境へコピーして検証。両環境の自動同期は想定しない |
| ログイン | メールのリンク・コードを使うパスワードレス。SNSログインも早期対応を目指す |
| 一般公開 | βで確認後にカタログの一般閲覧・未ログイン投票を開放 |
| 収益 | 正規購入先へのアフィリエイトを重視。個人DBの操作を妨げる広告は避けたい |
| 価格比較 | 販売先別の価格・セール価格表示は将来の検討対象 |
| 運用費 | 会社メンバーへの企画相談と併せて決定予定。予算・製品・契約は未決 |

通常の検索・推薦順位をアフィリエイト報酬の高さで変えない方針です。作者接続・SNSログイン・インポート認可は別の機能として扱います。

## 8．まだ決めていないこと

- **直前の議題：運営権限・管理画面。** 役割分担や個人DBの閲覧範囲の提案は、まだ承認前です。
- 共用タグ辞書の初期内容・採用基準・概念関係・検索の詳細。ベクトル利用は別途設計し、必須技術にはしていません。
- 同一作品・版の細かな判定、統合／分離時の投稿・票の扱い。
- 投票・信頼度の閾値、日付精度、再取得頻度、各種の保持期限。
- SNS認証・一括取得の実現性、提供条件、API費用。各候補への対応を保証する段階ではありません。
- サーバー・DB等の選定、性能目標、運用体制、公開時期、βに必要な実装範囲。
- マネタイズの具体条件、正式サービス名。
