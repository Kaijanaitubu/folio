# 検索候補に検索ヘルプの全予約語と対応する値を表示する

記録日：2026-10-16
管理ID：F-028
状態：実装済み・VPS反映済み（2026-10-16）
関連：[ロードマップ](ROADMAP.md)

## 現状

検索候補に、対応しているすべての検索ワードが表示されない。

## 希望する動作

検索ヘルプに掲載されている検索用の予約語と、その項目で指定できる内容（カテゴリの全選択肢など）を、すべて入力に応じて候補に表示する。

## 対象

- 検索ヘルプに記載された全予約語。別名・互換表記も含む。
- カテゴリなど、選択肢が定義されている項目の全対応値。
- 作者・タグなど、登録データに応じた値の候補。
- 現在の設定に応じた評価軸・マークと、ヘルプにある対応表記。

## 完了条件

- [x] ヘルプと候補表示を照合し、掲載された予約語に漏れがない。
- [x] カテゴリの中身を含め、定義済みの全対応値が入力に応じて候補に表示される。
- [x] 候補を選ぶと有効な検索式になり、空白や記号を含む値も正しく検索できる。
- [x] 登録データ・設定に応じた候補も表示される。
- [x] 通常入力だけでなく、空白・OR・否定の後や日本語入力中の候補選択も既存の検索構文を壊さない。
