# F-023：インポート画面の整理

実装日：2026-10-15。利用者がF-023への着手を承認。従来のブックマークレット・各商品／投稿インポーター・ジョブ処理を維持し、目的別の入口とファイルの前処理を整理する。

## 入口と導線

`#/imports` に4枚のカードを表示する。PCでは2列、スマホでは1列。上部に「取り込む」「取り込み履歴」「登録方法の設定」を常設する。各画面はURLの `view`・`service` で直接開ける。英語を基準に日本語も用意する。

- **リンクから**：作品URLを貼り付ける。登録済みなら既存詳細、未登録ならメタデータ取得後の未保存編集画面へ進む。既存のページ違い・重複候補確認を利用する。
- **ブラウザのブックマーク**：ブラウザのHTMLを受け付け、フォルダを維持する。
- **サービスのお気に入り**：nhentai・Pawchive・Kemonoを選ぶ。nhentaiは既存のAPIキー接続・Favoritesプレビュー・全件／選択取込。Pawchiveはこの画面で出力手順を開いてHTMLを読む。Kemonoは書き出したJSONを直接読む。
- **購入済み作品**：FANZA同人コミック・CGの出力手順とHTML選択。形式を選んで適用し、コミックとCGは別々に書き出す。DLsite購入一覧・DMMブックス本棚は準備中と明記し、対応したように表示しない。購入マークの自動付与は今回追加しない。

履歴には従来の全ジョブの進捗と結果へのリンクを表示し、停止・再開・候補の確認は既存ジョブ画面で行う。登録方法の設定にはFolioの接続先とブックマークレット設定を置く。nhentaiで再接続が必要なジョブからは、そのサービスの接続画面へ直接案内する。

## ファイルの共通確認

新しい `POST /api/import-list` は `kind`（bookmarks／pawchive／kemono／fanza）とファイルのテキストを受け、項目と件数概要を返す。既存の `/api/bookmarks` は互換維持する。ファイル上限12 MB、既存の変更用トークン・Origin制約を適用する。

読み込みだけではリモートの投稿取得・ジョブ作成・作品登録を行わない。ファイル内件数、選択可能、登録済みURL、ファイル内重複、未対応・対象外、お気に入り作者の除外件数を表示し、明示した「取込を開始」で既存ジョブへ渡す。Pawchive／FANZAの専用入口では別サービスのリンクを除外して件数を知らせる。ブックマーク入口は従来の混在リンクを許容する。

確認一覧は最初100件まで描画して追加表示できる。選択・全選択・解除・フォルダ絞り込みは全項目の状態へ適用し、0件では開始を無効にする。同時のファイル読込では最新の結果だけを表示する。画面を離れた後の応答や履歴ポーリングで旧画面を更新しない。開始ボタンは送信中無効にし、二重開始を防ぐ。

タイトル優先・タグ属性方式・関係するPawchive元リンク設定を「取り込みオプション」に折りたたむ。入口ごとに端末内へ選択を記憶し、以前のブックマーク設定も初期値として引き継ぐ。設定省略時は従来の取得タイトル優先・属性なしを維持する。ファイルを選び直したり画面を移動した場合は未開始のプレビューを破棄する。

取得失敗・同一作品／タグ候補の確認・すべてに適用・停止と再開は従来ジョブの処理を維持する。これらの取得後の件数は、読込前のプレビューで確定したように表示しない。
2026-10-16：Pawchiveの投稿メディア形式による除外・追加確認は解除した。FANBOXも投稿形式を問わず取得可能な公開メタデータを取り込む。表紙なしの投稿も取り込み可能と案内する。[現在の方針](PAWCHIVE-MEDIA-FILTER.md)。

## Kemono JSON

`{posts:[…],artists:[…]}` または投稿配列を受け付ける。投稿は `service`・`user`・`id` から、fanbox／patreonのみ `https://pawchive.pw/{service}/user/{user}/post/{id}` を生成する。正の数字のIDを検証し、未知のURLを実行・取得しない。タイトルは文字列として最大4096文字。本文・添付・埋め込み・認証情報などは項目やジョブへ渡さない。

作者のお気に入りから全投稿を取得しない。未対応サービスは件数だけ示し、同じサービス＋投稿IDはファイル内重複として選択不可にする。対応投稿に不正IDがある場合はファイル全体を拒否し、不完全な一覧を成功扱いしない。JSON不正・投稿一覧なし・上限超過は明確なエラーにする。0件／対応投稿なしでも除外件数を表示し、登録を開始できない。
