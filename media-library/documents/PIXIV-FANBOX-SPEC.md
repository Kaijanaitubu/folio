# Pixiv・PixivFANBOX メタデータインポーター

2026-10-16。ユーザー依頼：両サイトからタイトル、表紙、作者名、タグを取得する。

## 対応範囲と操作

- Pixiv：`https://www.pixiv.net/artworks/123`、言語付き `/en/artworks/123` 等、旧 `member_illust.php?illust_id=123`。
- FANBOX：`https://creator.fanbox.cc/posts/456`、`https://www.fanbox.cc/@creator/posts/456`、`https://www.fanbox.cc/posts/456`。
- 個別インポート、Importsの「リンクから」、OS共有、ブックマークレット、ブラウザのブックマークHTMLから使える。登録済みURLは既存作品を開き、明示的な再インポートでは既存の上書き・マージ・そのままの確認を使う。
- 以前作成したブックマークレットはサイト許可リストが古いため、Importsの登録方法設定から更新する。
- タグはサイトの原表記で取り込み、nhentai等と同じ未指定／既存の最多属性の設定を適用する。翻訳されたタグを別名として自動追加しない。
- 取得元ラベルは `Pixiv` / `FANBOX`。カテゴリ、言語、ページ数、サークル等は推定しない。評価・マーク・レビューを取得・変更しない。
- 作者トップ、Pixiv小説、シリーズ、ブックマーク／支援一覧の一括取得は今回の対象外。アニメーションや動画本体も取得しない。

## データ取得

Pixivの公開Web JSON `https://www.pixiv.net/ajax/illust/{id}?lang=ja` の title / userName / tags.tags[].tag を使う。
表紙は urls.regular / small / thumb / mini の順。未ログイン時に空の場合、userIllustsのうち対象IDと一致する項目の公開サムネイルURLだけを利用する。隣接作品や作者アイコンは使わず、元画像URLを推測・再構成しない。サムネイルは元サイトでトリミングされた小さい画像の場合がある。

FANBOXは公開Web JSON `https://api.fanbox.cc/post.info?postId={id}` の body.post（旧body直下にも対応）から title / user.name / tags[] / coverImageUrl（なければimageForShare）を読む。支援者限定投稿でも、匿名アクセスで返される公開メタデータ・公開表紙だけを使い、限定本文や添付を取得しない。

いずれも固定のWebエンドポイントであり、将来の応答形式や提供継続は保証されない。ログインCookie・トークンの登録機能は設けない。ログイン必須・非公開・削除済み等の場合はエラーを示し、手入力できる状態を保つ。表紙だけがない場合は警告とともに他のメタデータを返す。

## URL比較と既存データ

Pixivは作品ID、FANBOXは投稿IDで同じ投稿として比較する。HTTP/HTTPS、言語パス、追跡クエリ、アンカー、FANBOXの作者サブドメイン／@表記は同じキーへ正規化する。実際に保存するURL文字列は書き換えない。
移行15で既存リンクの比較キーと所有権索引のみ更新する。同一投稿が複数作品に登録されていても自動統合・削除しない。作品ID、本文、評価、リンク文字列は保持する。
Pawchiveから生成したFANBOXの副リンクも同じ投稿IDで照合される。

## 表紙とネットワーク

画像URLはi.pximg.netの作品画像経路、pixiv.pximg.netのfanbox/public/images/post経路を限定許可する。制限付き画像経路、作者アイコン、任意のホストは取得しない。プレビュー、ギャラリー、詳細、共有スナップショットで既存RAM中継を使い、画像はDB・ディスクへ保存しない。

取得先のDNSを確認して公開IPへTLS接続を固定する。自動リダイレクトなし、メタデータ・画像各4 MiB、接続後の全体期限20秒、JSON/MIME・投稿ID・タグ数・文字数・画像署名を検証。サイト別のメタデータ要求は1秒間隔。バッチの一時停止・中止に従う。HTTP 429等は既存ジョブの失敗・再試行として扱い、高頻度の自動再取得は追加しない。

## 検証記録

- 実接続で両サイト各1投稿のタイトル・作者・タグ・公開表紙URLを取得。Pixivは通常画像URLが空でも対象投稿のサムネイルを取得でき、FANBOXは支援者限定本文がnullのまま公開表紙を取得できた。表紙JPEG各21,733 / 300,983 bytesをRAM内で確認し、作品登録なし。
- 新規Python10テストは成功。URL変種、不正ホスト／DNS／リダイレクト／上限、匿名サムネイルと隣接投稿の区別、FANBOX旧新応答、RAMキャッシュ、キャンセル、HTTP再インポート、ブックマークの属性方針、比較キー移行を確認。
- Python全261件：256成功、3スキップ、2失敗。失敗はtest_serverの旧display_alias前提2件で、Git HEADの隔離コピーでも同一失敗を確認済み。今回の変更による失敗ではないが、全件成功とは扱わない。
- Nodeの既存・新規15スクリプト成功。ブックマークレット、共有経路、再インポート、表紙描画、日英表示等。ブラウザ操作接続が利用できなかったため、実ブラウザの目視確認は未実施。
