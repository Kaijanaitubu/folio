# サービス名の見直し

記録日：2026-10-16  
管理ID：F-037  
状態：要望記録済み・検討未着手  
関連：[ロードマップ](ROADMAP.md)

## 背景

「Folio」は耳馴染みがよいため仮に使っているが、正式なサービス名としてはあまり良い名前ではないと感じており、改めてきちんと考えたい。

## 検討したいこと

- 個人向けライブラリから将来の公開版まで使える名称の方向性。
- 日本語・英語での読みやすさ、覚えやすさ、表記のしやすさ。
- 作品ライブラリ／発見・整理の用途を表す名前にするか、用途を限定しない名前にするか。
- 候補を絞った後に、ドメイン・既存サービス名・商標との衝突を確認する必要性。
- 名称決定後に変更が必要となるアプリ内表示、リポジトリ、ドキュメント、公開URL等の範囲。

## 完了条件

- [ ] 名前に求める条件と避けたい印象を整理する。
- [ ] 方向性の異なる候補を複数提示し、日本語・英語での読み方と意味を説明する。
- [ ] 候補が絞られたら既存名・ドメイン等の衝突を調べる。
- [ ] 最終名称と切り替え範囲をユーザーが決める。
