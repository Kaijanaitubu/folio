# 詳細・編集画面のプロトタイプ配置への調整

2026-10-24。本人の依頼により、本番の詳細・編集画面の配置を[会議用プロトタイプ](WORK-UI-PROTOTYPE.md)へ合わせた。試作用の詳細／編集タブ、サンプル切替、PREVIEW表示、優先度設定、根拠入力欄、未対応の説明ダイアログなどを本番へ追加する作業ではない。

## 配置

| 画面 | 変更 |
| --- | --- |
| 詳細：PC | 左列に表紙と既存の「ソースを開く」。右列に分類と共有・削除・編集の3アイコン、タイトル、作者／サークル、言語・ページ数・代表日付を配置 |
| 詳細：個人記録 | 概要の下に総合評価・独自評価。既存のマークメニューを同ブロック右上へ移動 |
| 詳細：メタデータ以降 | タグ、二次創作時の原作・キャラクター、シリーズ、レビュー、ソースリンク、詳細情報の順。原作・キャラクターの値は一次創作／未設定時も詳細情報へ残す |
| 詳細：下部 | 年齢・AIを並べ、既存の収録先・逆方向の収録作品を右列内へ配置。詳細情報は常時表示のまま |
| 編集：PC | 画面全体の幅を使い、左列に見出し・入力中の表紙・画像URL・保存済み表紙の比較、右列に4セクション |
| 編集：基本情報 | タイトル、3分類、作者／サークルの2列、タグ、必要な場合の原作／キャラクターの順 |
| 編集：リンク | 既存のリンク情報は初期展開。役割・ページ数を並べ、言語と日付をその下へ配置。利用者が閉じた状態は編集中に維持 |
| 編集：個人記録 | 評価の見出しと入力記号を行でそろえ、マークとレビューを区切る |
| 編集：スマホ | 上部に小さな表紙と画像URLを並べ、その下に4セクション。360pxの狭い幅では複数列の入力を1列へ変更 |
| 保存操作 | 固定バーとページ末尾の保存／キャンセルを維持。固定バーを本文の幅へ合わせ、入力フォーカス中は非表示 |

既存の表紙比較、再試行、ブックマーク名候補、メタデータ追加・編集・一括解除、取り込み、既存作品への統合、評価の記号・段階数、マーク、未保存移動の確認を維持する。リンク追加は一覧末尾のまま。詳細の表紙とリンク行本体は外部リンク、リンク右端の矢印だけが補足情報を開閉する。

表示値の採用ルールは変更していない。ページ数・代表日付は主リンク、言語は全リンクの和集合。試作に残っているソース優先順位・最大ページ数・最古日付の計算を再導入しない。未記録のページ数・日付を新しい情報として追加表示しない。

既存のナビゲーション、検索ユーティリティバー、英語／日本語、テーマ選択を維持。公開共有スナップショットのデザインや内容は今回変更していない。

## 確認

ローカルの専用確認用DBに架空作品・自作の試作用表紙を用意し、本番データを使わずブラウザーで確認した。

- PCでプロトタイプと本番候補の詳細・編集画面を比較。
- 390px・360px幅、英語／日本語の配置を確認。表示範囲の横方向にはみ出しなし。
- 10段階を含む独自評価と、マーク展開時の折り返しを確認。
- 入力フォーカス中の固定保存バー非表示、フォーカスを外した後の保存、詳細への遷移を確認。
- 実在しない日付で保存を止め、入力を保持し、日付を直して保存できることを確認。
- 試作用の詳細／編集タブが本番候補に存在しないことを確認。
- Nodeの`test_*.mjs`全24本が成功。画面生成処理を別モジュールへ移したため、既存の詳細操作・レビュー全文維持のテスト参照先を更新。
- 本番の新規編集画面を実ブラウザーで開き、900px幅でもフォームと固定バーの左右端が一致し、横にはみ出さないことを確認。作品は保存していない。

スマホ幅の確認はデスクトップブラウザーの表示領域変更によるもの。実機のソフトウェアキーボードによる表示領域変化は今回も未検証。フォーカス判定による固定バー非表示と区別する。
